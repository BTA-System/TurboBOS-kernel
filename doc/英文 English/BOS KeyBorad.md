# BOS Keyboard Key Number Table

This table defines the custom keyboard key numbering rules used by the BOS operating system. It is **not** compatible with any existing keyboard scan codes or keyCode standards.

## Key Number Assignment Principles

- Commonly used keys are assigned smaller key numbers.
- The Space key is placed first (key number 1).
- Arrow keys follow (key numbers 2–5).
- Uppercase letters A–Z (key numbers 6–31).
- Lowercase letters a–z (key numbers 32–57).
- Control keys (starting from key number 58).

## Notes

- This key number table is intended for internal use within the BOS system only and is unrelated to real keyboard scan codes or ASCII codes.
- The key numbers are assigned based on practicality and ease of memorization, with commonly used keys getting smaller numbers.

This table is used for the BOS keyboard driver and the BVM instruction set design.
