# BVM 指令集文档

## 指令格式说明
- **6 字节指令**: `[opcode] [dest] [src]` (每字段 2 字节)
- **4 字节指令**: `[opcode] [addr]` (跳转、单操作数指令)
- **2 字节指令**: `[opcode]` (无操作数)

## 寄存器编码表

| 寄存器 | 编号 (十六进制) | 读写性 |
| :--- | :--- | :--- |
| AR | 0000 | 读写 |
| BR | 0001 | 读写 |
| CR | 0002 | 读写 |
| DR | 0003 | 读写 |
| ER | 0004 | 读写 |
| FR | 0005 | 读写 |
| GR | 0006 | 读写 |
| SP | 0007 | 读写 |
| AdR | 0008 | 读写 |
| AC | 0009 | 只读 |
| AE | 000A | 只读 |
| AZ | 000B | 只读 |
| ERR | 000C | 只读 |
| ERC | 000D | 只读 |
| PC | 000E | 读写（可通过JMP间接修改） |

*PC寄存器在Kernel中为十进制，实际传给BVM/程序时获取到的值都为二进制*

## 寄存器位数

| 寄存器 | 位数 |
| :--- | :--- |
| AR | 16 |
| BR | 16 |
| CR | 16 |
| DR | 16 |
| ER | 16 |
| FR | 16 |
| GR | 16 |
| SP | 16 |
| Adr | 16 |
| AC | 1 |
| AE | 1 |
| AZ | 1 |
| ERR | 1 |
| ERC | 16 |
| PC | 16 |

*AR~GR为通用寄存器，AC,AE,AZ,ERR为标志位寄存器，AdR,SP为指针寄存器（SP为栈指针，AdR为通用指针寄存器）。ERR,ERC都是系统调用寄存器标志*

## 特殊寄存器（BVM程序不可见，为内核常数）
| 寄存器 | 位数 | 备注 |
| :--- | :--- | :--- |
| SD | 16 | Start Data,DATA段起始地址，减去1为TEXT段末尾 |
| SS | 16 | Start Stack,Stack段起始地址，减去1为DATA段末尾 |
| ES | 16 | End Stack,Stack段终止地址，加上1为HEAP段起始地址 |
| BASE | 16 | RAM起始地址，常量保持0x0000 |
| LIMIT | 16 | RAM终止地址，常量保持为0xFFFF |

*对于LIMIT寄存器，我们未来将会看看是否添加更多地址线，该寄存器的位数会发生变化。仅给内核使用*
